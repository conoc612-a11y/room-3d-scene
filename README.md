# 고른 공간

## 주소
https://conoc612-a11y.github.io/room-3d-scene/

## 어디를 골랐나
- 사무실 회의실에서 열린 유공자 표창 수여식 장면. 스크린 앞 발표대와 참석자들이 앉은 테이블이 보인다.
- 공개해도 되는 곳이라고 판단한 근거: 사적 공간이 아니라 공개 회의(표창 수여식)라 공개해도 무방하다고 판단했다.

## 어떻게 찍었나
- 길이 12.1초, **1280×720 (720p)**, 뽑은 장수 24장
- 카메라가 퍼진 정도 **0.006** (0.1이 기준선) — 카메라가 거의 고정된 채 찍혀 기준선의 6% 수준. 걸어 다니며 찍은 영상이 아니라 삼각대에 가까운 촬영
- 나온 점 **약 320만 개** (3,201,496개, 이상치 제거 후 3,105,452개)

## 폰에서 첫 화면까지
실제 폰 두 대가 없어 서로 다른 네트워크 위치 두 곳에서 `index.html` + `scene.sog` 내려받는 시간을 재서 대신했다. (자바스크립트 파싱·WebGL 초기화 시간은 빠져 있어 실제 체감 시간은 이보다 조금 더 걸린다.)

- 집 네트워크 (한국): index.html 0.42초 + scene.sog 2.44초 ≈ **2.9초**
- 코랩 VM (구글 클라우드, 해외): index.html 0.30초 + scene.sog 1.14초 ≈ **1.4초**

## 안 나온 자리
splat-transform 으로 위·좌·우에서 렌더링해 직접 확인한 결과, 이 장면은 **부피가 있는 방이 아니라 종이처럼 얇은 굽은 껍질**로 무너져 있다. 처음 찍은 각도에서는 그럴듯해 보이지만 옆이나 위에서 보면 두께가 거의 없다.

- **원인**: 카메라 퍼짐 비율이 0.006으로 기준선(0.1)의 6%밖에 안 된다. 걸어서 시차를 만들지 않고 거의 한 자리에서 찍었기 때문에, 모델이 깊이를 삼각측량이 아니라 추정에 의존했고 그 결과가 굽은 한 장의 판으로 뭉쳤다.
- **검게 빈 곳**: 카메라 시야 밖(좌우 벽, 뒤쪽 벽, 천장 대부분)은 어느 사진에도 안 잡혀 통째로 비어 있다. 껍질을 옆에서 보면 그 뒤로 바로 암전된다.
- **고치는 법**: 같은 공간을 다시 찍을 거면 가로로 들고 걸어 다니며 좌우로 이동해 시차를 만들어야 한다.
